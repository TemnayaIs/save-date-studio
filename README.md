# Save Date — электронные приглашения

🔗 **https://save-date-studio.ru**

Бумажное приглашение теряется на холодильнике, а сообщение «свадьба 12-го, приходите» тонет в чате. Save Date — это одна ссылка, по которой гость открывает целое приглашение: с музыкой, обратным отсчётом, программой дня, картой, анкетой и вишлистом.

Пара выбирает дизайн, заполняет его в редакторе за вечер, оплачивает и рассылает гостям. Ответы гостей приходят в Telegram.

## Что внутри

**Дизайны.** У каждого макета своя вёрстка и своя заставка: где-то распахиваются двери, где-то вскрывается конверт, а в «Туали» развязывается шёлковый бант. Анимации — CSS и видео, которые подстраиваются под цвета темы и не показывают системную кнопку Play на iPhone.

**Редактор для пары.** Текст, фото, музыка, цвета, порядок блоков; предпросмотр на телефоне и компьютере в реальном времени. Без регистрации — доступ по секретной ссылке.

**Для гостей.** Анкета (RSVP) с выбором меню и аллергиями, рассадка по столам, вишлист, где подарок можно «забронировать», чтобы не подарить два одинаковых тостера. По личной ссылке приглашение обращается к гостю по имени.

**Админка.** Конструктор тем, визуальный редактор блоков с перетаскиванием, замена видео в дизайнах, палитра всего сайта с историей версий — неудачную можно откатить в один клик.

## Оплата

Подключена ЮKassa: пара жмёт «Оплатить и опубликовать», платит картой или через СБП на странице ЮKassa — и приглашение публикуется само, без участия админа.

- **Подделать оплату нельзя.** Сайт не верит ни уведомлению, ни странице возврата: статус платежа и сумма каждый раз перепроверяются запросом к API ЮKassa.
- **Двойных списаний не будет.** Каждый запрос на создание платежа уходит с ключом идемпотентности, повтор уведомления не публикует приглашение второй раз.
- **Чек по 54-ФЗ** формируется автоматически и приходит покупателю на почту.
- **Промокоды** со скидкой, сроком действия и лимитом использований. Лимит защищён блокировкой строки в базе — два одновременных заказа не «проскочат» последний промокод.
- Админу в Telegram сразу приходит сообщение о каждой оплате.
- Если ключей ЮKassa нет, сайт не ломается — переходит в режим заявок, и оплата принимается вручную.

## Безопасность
Двухфакторный вход в админку (TOTP), загружаемые файлы проверяются по содержимому, а не по расширению, на гостевых страницах — только свои ссылки и файлы.
